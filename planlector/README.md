# ¿Qué es la electrónica digital?
La electrónica digital es una rama de la electrónica que trabaja con señales discretas generalmente dos: 0 y 1 el cual se basa en el sistema binario
# ¿En qué se basa el funcionamiento de la electrónica digital?
La electrónica digital se basa en el sistema binario, utilizando solo dos estados: alto 1 y bajo 0
# ¿Qué ventajas nos ofrece la electrónica digital?
-Uso del sistema binario.
-Mayor resistencia al ruido.
-Capacidad de almacenamiento y procesamiento de datos.
-Facilidad de programación y automatización.
-Integración en circuitos complejos
# ¿Por qué no le afecta el ruido eléctrico? ¿Puede originar ruido eléctrico? ¿Qué problemas origina esto?

## ¿Cómo podemos aplicar la placa de Arduino al control automático de la agricultura?
Arduino puede usarse para controlar sistemas de riego automatizado. Utilizando sensores para medir la humedad del suelo, Arduino puede activar o desactivar válvulas de riego para asegurar que las plantas reciban la cantidad adecuada de agua.
## ¿Cómo podemos incorporar la placa de Arduino para controlar los datos de nuestro prototipo de invernadero en el aula?
Arduino puede usarse para crear sistemas de monitoreo agrícola. Sensores de humedad del suelo, temperatura, humedad atmosférica, y otros parámetros pueden conectarse a placas Arduino. Estos sensores proporcionan datos en tiempo real que permiten a los agricultores tomar decisiones informadas sobre el riego, la fertilización y otros aspectos del cultivo.
